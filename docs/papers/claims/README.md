# Evaluation protocols

The [protocols](protocols/) describe historical study designs, metric choices, coverage checks,
comparison budgets and amendments. The private scheduling and claim registry are not included.
The corresponding [verification records](../tools/verified/) preserve measured results and
limitations; see the [benchmark summary](../parity.md) for their interpretation.

A headline comparison needs a declared protocol before measurement, identical expected/scored
view sets (or an explicit common-view rule), a named scorer, matched budgets and the required
seed repeats. A change after seeing results is a new exploratory variant, not independent
confirmation. Results from partial coverage remain provisional.
