Vauss 0.1.24-rc makes fisheye footage work end to end and fixes a frame-decoding bug.

- **Fisheye input.** `vauss run --camera-model opencv-fisheye` now solves, seeds and trains fisheye footage on the native Kannala-Brandt (KB4) lens model instead of refusing it. Fisheye captures imported with `--trust-poses` are seeded from triangulated points rather than the random initializer, depth seeds unproject through the fisheye lens, the black area outside the image circle is masked out of training, and held-out scoring is masked to the lens circle. A COLMAP folder (`images/` + `sparse/0`) with fisheye intrinsics is accepted as input. On a real fisheye room capture, held-out PSNR inside the lens circle rose from 15.5 dB (0.1.23-rc) to 23.7 dB with the same 15 held-out frames; on the FIORD MeetingRoom Insta360 fisheye scene (CC BY 4.0), `--camera-model opencv-fisheye` now places 202/202 frames (0.1.23-rc refused it) and the COLMAP-folder input places 203/203. Surfel and mesh outputs train on an undistorted pinhole crop (up to 120° across) instead of ignoring the lens.
- **Extracted frames decode correctly everywhere.** Since 0.1.10, frames written by frame extraction used a JPEG encoding that the `image` crate decoded with zeroed colour. The trainer and held-out scoring use a different decoder and were not affected, so published quality numbers stand; CPU-side helpers that read frames (depth prior, learned SfM rescue, sensor-depth seed colours, game-export view images, off-path view scoring) now see correct colours. Extracted frames are about 3–6% larger.
- **Groundwork for 360 input.** Internal panorama splitting and rig-solve code ships but is not yet reachable from `vauss run`; 360 equirect input arrives in the next release.

Known limitations: a Blender camera cannot reproduce a fisheye lens, so the Blender pack's capture-camera import is pinhole-only (the splat, mesh and voxels are unaffected, and the pack README says so). `--camera-model auto` detects circular fisheye frames; full-frame fisheye footage may still need the explicit flag. Quality evidence so far is two indoor captures.
