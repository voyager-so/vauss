Vauss 0.1.23-rc fixes trusted-camera import quality and hardens the public release scan.

- `--trust-poses` imports without seed points are now seeded from points triangulated under the imported cameras (COLMAP `point_triangulator` with fixed poses and exact K), instead of the random +Z initializer. On a 70-view test capture, held-out PSNR rises from 15.4 dB to 27.15 dB, matching the SfM-camera control (27.47 dB). Imported poses and intrinsics are never altered: poses are verified unchanged after triangulation, held-out views are excluded, and any failure falls back to the random initializer with a loud warning and run-report fields (seed point count, source, reason).
- `FULL_OPENCV` and `OPENCV_FISHEYE` imports are not seeded in this release; they fall back with the warning.
- Trusted and capture-fallback training now validate the real trainer configuration before any GPU work.
- Public release scanning classifies the TruffleHog Brotli mis-detection of Mach-O executables structurally (validated Mach-O header and load commands, no duplicate archive members, unchanged bytes rescanned with the standard framing prefix); every other scan error still refuses publication.

Known limitations: the seed step needs the bundled COLMAP; one 70-view capture is the only quality evidence so far. Views 100/101/103/104 of the corrected241 demo model are still detected and flagged, not cured.
